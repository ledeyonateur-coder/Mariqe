Confidentialité

Vos images restent chez vous

Toute la transformation (couleurs, points, fichiers machine) est faite dans votre navigateur. Vos images ne sont pas envoyées sur un serveur.

Mes projets

« Enregistrer » garde vos projets dans le stockage de votre navigateur, sur votre appareil. Vous pouvez les supprimer à tout moment.

Synchronisation et galerie (facultatives)

Seulement si vous les utilisez : la synchronisation envoie vos projets, chiffrés par votre code personnel, vers notre stockage pour les retrouver sur un autre appareil ; la galerie communautaire publie le motif que vous choisissez de partager (nom, aperçu, fichier). Vous pouvez supprimer un partage avec son code.

Statistiques

Nous mesurons la fréquentation avec Vercel Web Analytics, sans cookie et sans identifier les visiteurs.
