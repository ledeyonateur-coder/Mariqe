Quel format pour ma machine ?

FormatMarquesCouleurs dans le fichier
EXPbernette Chicago 5/7, Bernina, MelcoNon : la machine s'arrête à chaque couleur
PESBrother, Baby Lock, bernette b70-b79, DecoOui (nuancier Brother)
JEFJanome, Elna, KenmoreOui (nuancier Janome)
VP3Pfaff, Husqvarna VikingOui (couleurs exactes)
DSTTajima, Barudan, Ricoma et la plupart des machines proNon

Dans le doute, le DST est lu par presque toutes les machines. FilTrace sait aussi ouvrir ces formats pour les redimensionner ou les convertir (bouton « Fichier broderie »).
